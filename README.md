# まなぼき 簿記3級

簿記3級を、スキマ時間でゼロから合格まで。無料・広告なし・登録なし。

**使う: https://roguepink.github.io/boki3/**

## できること

- **レベルに合わせて出題** — 分野ごとの習熟度で、初級 → 中級 → 上級と問題が少しずつ難しくなる。最初に14問のレベル診断
- **説明は3段階** — 🧒やさしく(小学生でもわかる)/📘ふつう/🎓くわしく(試験のひっかけ・実務)。いつでも切りかえ
- **まちがえた所の補足** — 「借方と貸方が逆」「この科目は使わない」「金額がちがう」などを、答えに合わせて説明
- **仕訳はタップでも入力でも** — 科目をえらぶ/文字で書く(ひらがな・別名OK)/🎤声で入れる
- **復習** — まちがえた問題が、10分後・1日後・3日後・1週間後…と忘れたころに戻ってくる
- **レッスン** — 図つきのカードで読む教材(T字の勘定・仕訳・5つのグループ・期間の図・請求書など)
- **模擬試験** — 本番と同じ 第1問(仕訳15問・45点)・第2問(20点)・第3問(35点)、60分、採点つき
- **会社の経理で使う取引** — 交通費・給料と預り金・社会保険料・振込手数料・請求書と領収書
- **2027年4月からの新しい範囲にも対応** — 受ける時期をえらぶと、範囲を切りかえる(手形あり/なし・定率法・除却など)
- 合格予想スコア・連続日数・4週間のカレンダー・用語と科目のじてん(170語以上)
- ホーム画面に入れると、電波がなくても使える。記録はスマホの中だけ

## しくみ(作る人むけ)

- ビルドなし・外部ライブラリなし。`index.html` + `css/app.css` + `js/*.js`
- 中身(問題のひな型・レッスン・用語・模擬試験)は `js/data/*.js`。書き方は [SPEC.md](SPEC.md)
- 問題は「ひな型」から金額・場面を乱数で変えて作るので、同じ問題ばかりにならない
- 確認の道具: `tools/check_data.py`(中身のまちがい探し)・`tools/flow.py`(指の操作と同じ流れ)・`tools/test_check.py`(答え合わせの判定)・`tools/shot.py`(画面を撮る)

日本商工会議所の公式アプリではありません。
